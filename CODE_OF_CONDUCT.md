# Code of Conduct

Pollramp exists so that every voter can get into their polling place. We expect the same respect in
how we work together.

## Our standards

- Be welcoming and patient, especially with people new to open source or to accessibility.
- Use person-first or identity-first language as the people you're talking about prefer. Don't use
  disability as an insult.
- Assume good intent, give specific and kind feedback, and accept feedback gracefully.
- Don't harass, demean, threaten or publish anyone's private information.
- Keep discussions about voting non-partisan. This project is about access, not outcomes.

## Scope and enforcement

This applies in all project spaces: issues, pull requests, discussions and events. Report
unacceptable behaviour privately to the maintainers through a
[security advisory](https://github.com/lobojoel2003/Pollramp/security/advisories/new) or by contacting
a maintainer directly. Reports will be reviewed promptly and kept confidential. Maintainers may
remove content and temporarily or permanently ban participants who violate this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version
2.1.
